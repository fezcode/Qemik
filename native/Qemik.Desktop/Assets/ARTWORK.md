# Qemik wave icon

Generated with the built-in image-generation tool. The original project asset is `qemik-artwork.png`; `Brand.cs` renders it with rounded corners. The desktop artwork export produces PNGs at Windows icon sizes, which are packed into `qemik.ico`.

## Final generation prompt

Use case: logo-brand. Create one finished premium Windows desktop app icon for Qemik, a QEMU virtual machine app whose name plays on Turkish 'kemik', bone. Completely new art direction. Square 1024x1024 canvas, icon artwork fills the canvas edge-to-edge, no outside mockup surface, no extra padding. Rich ink-black to midnight-teal background with three broad flowing ocean/aurora-like waves sweeping behind the central mark; layered teal, emerald and soft chartreuse light, elegant subdued gradients, finely restrained depth. Central focal symbol is a bold sculpted ivory Q monogram: a thick rounded almost-circular ring with a diagonal bone-shaped stroke forming its lower-right tail; recognizably Q at tiny sizes and subtly bone-inspired, two rounded lobes at bone ends. This should look like a refined modern desktop application icon, intentional graphic composition with subtle dimensional highlights rather than a generic stock logo. Central mark occupies about 60% of square, high contrast and clean silhouette. Background wave contours add motion and atmosphere without competing with the white monogram. No monitor, no computer outline, no skull, no paw, no text or wordmark other than the symbolic Q, no watermark, no presentation board, no multiple variants. Full-bleed square artwork; application will round its corners.
