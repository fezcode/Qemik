# Qemik v0.1.1

The first public release of Qemik, a Windows desktop manager for QEMU virtual
machines built with C# / .NET 10 and Avalonia.

## Changes

### ✨ Windows installer
- Qemik now ships as `Qemik-Setup-0.1.1.exe`, a per-user Forge installer
  (`%LOCALAPPDATA%\Programs\Qemik`, no administrator rights needed) with the
  `huh` wizard theme, Qemik's icon, the MIT license agreement, and optional
  Desktop and Start Menu shortcuts.
- Uninstalling never touches your machines: the library in
  `%LOCALAPPDATA%\Fezcode\Qemik` (disks, firmware, downloaded media) is kept.

### ✨ Guest windows
- Closing a running guest window now asks **Do you want to force close?**
  **Force close** immediately shuts the VM down; **Cancel** keeps it running.
  In-app help and settings text describe the new behavior.
- Guests can no longer outlive Qemik. Every QEMU process now belongs to a
  Windows job object that shuts it down when Qemik's process ends, including
  after End task, a crash or sign-out. Previously the guest kept running with no
  Qemik left to control it.

### ✨ Virtual machines
- Create, edit and run QEMU machines with memory, CPU, storage, firmware,
  display, network and sound settings.
- Official Linux image discovery with resumable downloads and checksum
  verification, plus local ISO attachment and live media ejection.
- A dedicated guest window with a native GPU (VirGL) path, keyboard/mouse
  capture, fullscreen, power controls, automatic resizing, text clipboard via
  spice-vdagent, and shared folders.

### 🔧 Versioning
- The version shown by `--version`, the sidebar footer, the About card and the
  HTTP User-Agent now comes from the build instead of being hardcoded.

## Windows installation

1. Download `Qemik-Setup-0.1.1.exe` and run it. The .NET runtime is included.
2. QEMU is **not** part of this installer. Open **QEMU engine** in Qemik to
   download and verify QEMU for Windows, or point Qemik at an existing install.
3. For faster x86 guests, enable Windows Hypervisor Platform and use a QEMU
   build with WHPX support.

Windows x64 is the only supported host.

## Validation

- `build.ps1 -Test -Publish` on Windows x64: build, unit, protocol and
  offscreen UI tests pass. The disposable-QEMU and real-guest checks are opt-in
  and were skipped in this run.
- `build-installer.ps1` verified the Setup's embedded Forge manifest: checksum,
  identity and version, `huh` theme, wizard steps, MIT license, shortcuts,
  registry entries, the patched Setup icon, the preserved library and the payload
  files. It also checked that no QEMU or guest media is bundled.
