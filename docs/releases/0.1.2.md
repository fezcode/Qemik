# Qemik v0.1.2

Machine settings are now dropdowns instead of text boxes.

## Changes

### ✨ Settings are dropdowns
- Every setting that picks from a set of values is a dropdown, and the value a
  new machine of that guest type would get is marked **(default)**.
- Machine type, CPU model, CPU feature flags and network device are read from
  your installed QEMU, so the lists match your build. When QEMU is not found, a
  built-in list is shown, with a note saying so.
- Memory, CPU cores, threads and new-disk capacity use presets sized to this PC.
  Boot order has plain labels such as **Disk only**, and MAC address offers the
  current address or a new random one.
- CPU feature overrides are added from a list of the flags QEMU recognizes, as
  `+flag` or `-flag`, and shown as removable chips.

### ✨ Host devices
- USB passthrough lists the devices plugged into this PC as checkboxes. Saved
  devices that are unplugged stay checked and are marked *not connected*.
- The TAP adapter setting lists the TAP and Wintun adapters on this PC.

### ✨ Custom values
- Dropdowns whose value goes straight to QEMU end in **Custom…**, which opens a
  text box for any other value. A saved value missing from the list opens there
  unchanged instead of being replaced, so existing machines keep their settings.

## Windows installation

1. Download `Qemik-Setup-0.1.2.exe` and run it. It upgrades an existing Qemik
   install in place, and your machines in `%LOCALAPPDATA%\Fezcode\Qemik` are kept.
2. QEMU is **not** part of this installer. Open **QEMU engine** in Qemik to
   download and verify QEMU for Windows, or point Qemik at an existing install.

Windows x64 is the only supported host.

## Validation

- `build.ps1 -Test -Publish` on Windows x64: build, unit, protocol and
  offscreen UI tests pass. The disposable-QEMU and real-guest checks are opt-in
  and were skipped in this run.
- The settings lists were checked against an installed QEMU 11.1, and an
  existing Ubuntu machine's saved settings open unchanged with every value
  selected.
- `build-installer.ps1` verified the Setup's embedded Forge manifest: checksum,
  identity and version, `huh` theme, wizard steps, MIT license, shortcuts,
  registry entries, the patched Setup icon, the preserved library and the payload
  files.
